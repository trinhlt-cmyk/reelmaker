# Nội dung của bên thứ ba

Code của reelmaker thuộc tác giả, không cấp giấy phép dùng lại (UNLICENSED). Các phần dưới đây thuộc bên thứ ba,
giữ giấy phép riêng của chúng.

## Thư viện

| Thành phần | Giấy phép | Nguồn |
|---|---|---|
| `lib/lottie.min.js` (lottie-web 5.12.2) | MIT | https://github.com/airbnb/lottie-web |
| gl-transitions (npm, chuyển cảnh `gl:…`) | MIT | https://github.com/gl-transitions/gl-transitions |
| puppeteer-core (npm) | Apache-2.0 | https://github.com/puppeteer/puppeteer |
| KaTeX (kiểu `math`, tải từ jsdelivr khi chạy) | MIT | https://katex.org |
| Phông chữ Google Fonts (tải khi chạy) | SIL Open Font License | https://fonts.google.com |
| edge-tts, VieNeu-TTS, faster-whisper (cài bằng pip) | theo từng gói | xem README |

## Âm thanh

`sfx/`: tiếng Kenney "Interface Sounds" (CC0) và tiếng tự tạo bằng `sfx/make_*.py` — chi tiết trong `sfx/README.md`.
